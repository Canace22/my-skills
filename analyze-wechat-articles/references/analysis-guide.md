# 指标口径与报告模板

## 指标字典

| 指标 | 使用方式 | 注意事项 |
|---|---|---|
| 阅读人数 | 衡量累计触达 | 观察天数不同不可直接横比 |
| 平均阅读时长 | 衡量停留 | 受文章长度、媒体形式影响 |
| 完读率 | 衡量读至末尾的比例 | 不等同于关注或商业价值 |
| 新增关注 | 衡量正向关注贡献 | 缺少取关时不能称为净增 |
| 分享率 | 分享 / 阅读 | 小阅读基数会放大比率波动 |
| 关注转化率 | 新增关注 / 阅读 | 同时展示分子、分母和比率 |
| 互动率 |（分享 + 喜欢 + 点赞 + 留言 + 收藏）/ 阅读 | 赞赏金额和听全文不计入默认互动率 |

## 时间口径

按自然日计算观察天数：

`观察天数 = min(快照日期 - 发布日期 + 1, 30)`

若文章在快照日前不足 30 天，只能称为“截至快照日的累计数据”。跨文章比较优先使用：

1. 相同的发布后 7 天窗口
2. 相同的发布后 30 天窗口
3. 比率指标，并保留小基数提醒

不要把后台“自然日趋势”与“单篇发布后累计”直接比较或相减。

## 样本解释规则

| 有效文章数 | 允许的表述 |
|---:|---|
| 1–7 | 描述、异常点、候选假设 |
| 8–14 | 探索性分组、方向性信号 |
| 15+ | 相对稳定的内容方向判断，仍不直接证明因果 |

分组比较还需满足：

- 每组至少 3 篇，最好 5 篇以上
- 使用一致观察窗口
- 同时比较中位数、绝对贡献和效率指标
- 标注标题、渠道、发布时间等潜在混杂因素

## 常用实验

- 标题实验：事件型标题与解决方案型标题，主题和正文尽量一致。
- 叙事实验：信息型正文与第一人称踩坑叙事，比较关注转化率。
- CTA 实验：有明确关注价值承诺与无 CTA，比较发布后 7 天关注转化。
- 场景系列：连续 3–5 篇同类工作流文章，避免用单篇判断品类。
- 节奏实验：保持 4 周固定频率，比较日均阅读和旧文长尾；不要提前宣称断更造成下降。
