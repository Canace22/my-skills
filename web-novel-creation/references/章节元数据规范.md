# 章节元数据规范

## 位置

- 章节文件：`chapters/第NN章-标题.md`（纯正文，无元数据）
- 元数据文件：`chapters/第NN章-元数据.md`（独立文件）

## 元数据文件结构

```markdown
# 第NN章 · 元数据

> 与 `第NN章-标题.md` 配对
> 最后更新：YYYY-MM-DD

## 基本信息

| 项 | 内容 |
|---|---|
| 章节号 | 第N章 |
| 字数 | 约N字 |
| 核心事件 | 一句话概括 |

## 叙事记录

| 项 | 内容 |
|---|---|
| 主推进 | 推剧情 / 推关系 / 推世界 |
| 主冲突 | 内在 / 人际 / 外在 |
| 节奏位置 | 钩子 / 压力 / 爆点 / 缓冲 |
| 章尾钩子 | 下一章为什么还要看 |
| 爽点 | 读者会爽的点 |

## 伏笔
- 本章埋的伏笔

## 备注
- 后续需要回填的内容
```

## 编号约定

⚠️ **以项目已有文件的命名为准**，不要改变编号格式。
- 用 `ls chapters/` 检查项目实际使用的格式
- 全局模板用 `第NNN章`（3位补零），但实际项目可能用 `第NN章` 或 `第N章`

## 何时生成元数据文件

- 简单项目（3章以内）：可不生成
- 复杂项目（多章、多人物、多伏笔）：建议每章生成
- 用户要求时：必须生成

## 常见错误

❌ 把元数据放在章节文件底部
❌ 把元数据放在章节文件标题下方（用 `>` 引用格式）
❌ 编号格式与项目已有文件不一致
✅ 元数据在独立的 `第NN章-元数据.md` 文件中
✅ 编号格式与项目已有文件保持一致
