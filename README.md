# my-skills

save some skills use in my work

目录型 Skill 使用通用的 `SKILL.md` + `scripts/` 结构，可按不同 AI 工具的约定复制或软链接使用。

## 目录

| Skill | 说明 |
|---|---|
| [ai-project-summary](ai-project-summary.md) | 项目/功能/bug 修复收尾时，生成结构化项目总结并提交进仓库 |
| [clean-wps-markdown](clean-wps-markdown/SKILL.md) | 清理 WPS Markdown 的标题层级、重复序号、缩进和无权限图片 |
| [video-face-mosaic](video-face-mosaic/SKILL.md) | 视频人脸批量打码，可指定保留某个人不打码；自动处理 HDR 色彩，避免成片偏色 |
