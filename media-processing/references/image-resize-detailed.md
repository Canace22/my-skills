# 图片尺寸调整补充

## 多端背景 / 壁纸常用尺寸

| 标签 | 尺寸 | 用途 |
|------|------|------|
| desktop_1920x1080 | 1920×1080 | 桌面标准 |
| desktop_2560x1440 | 2560×1440 | 2K |
| desktop_3840x2160 | 3840×2160 | 4K |
| mobile_1080x1920 | 1080×1920 | 手机竖屏 |
| mobile_1170x2532 | 1170×2532 | iPhone |
| mobile_1440x3200 | 1440×3200 | 大屏手机 |

输出目录按项目约定（比如游戏项目的 `assets/backgrounds/`），没有约定就问用户。

## 方案选择

- **不要默认模糊背景填充**：当原图比目标小很多时（如 278×188 → 1920×1080），模糊填充效果很差。应主动列出 3 种方案让用户选：
  1. 模糊背景填充 — 适合原图接近目标比例且分辨率不太低
  2. 直接拉伸 — 会变形
  3. 黑边填充 — 保持比例居中，上下/左右加黑边
- **用户说"这是原图"时不要再追问高清版本**，接受当前分辨率，给出最佳可用方案

## 能力边界（重要）

Pillow 只能做 **已有图片的变换**，不能做：
- **AI 图像生成**（生成新插画、概念图、美术风格图）→ 需要 DALL-E / Midjourney / Stable Diffusion
- **风格迁移**（把照片变成油画风、像素风等）→ 需要专门的模型

当用户要求"生成"而非"调整"时，**直接告知能力边界**，不要用 Pillow 勉强凑合。正确的做法：
1. 说明需要 AI 图像生成工具（推荐 Midjourney / DALL-E / SD）
2. 主动提供精确的英文 prompt 供用户复制到绘图工具
3. 如果当前工具自带生图能力，直接用它
