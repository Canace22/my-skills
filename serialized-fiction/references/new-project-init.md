# 新项目初始化流程

> 适用于从零开始创建新的小说项目。

## Step 0：创建目录结构

```
projects/<项目名>/
├── README.md              # 项目配置、发布包装、进度表
├── 立意卡.md               # 核心卖点、金手指、主冲突
├── canon/                  # 只读的历史/原作设定
│   ├── 历史背景.md          # 历史题材必需
│   └── 人物-<名字>.md       # 主要人物设定
├── fanon/                  # 可写的原创设定
├── outline/
│   ├── 卷1-大纲.md
│   └── 卷1-章纲.md
├── chapters/               # 正文 + 元数据
└── notes/
```

## Step 1：题材 → 立意卡

调用 `story-seed-skill`，输出 `立意卡.md`。

必填六项：一句话卖点、主角金手指、主冲突、目标平台、核心人物三件套、主弧线 A→B。

## Step 2：立意卡 → 卷大纲 + 章纲

调用 `outline-forge-skill`，输出卷大纲和章纲。

## Step 3：补充 canon 设定

为每个主要人物创建 `canon/人物-<名字>.md`。
历史题材创建 `canon/历史背景.md`。

## 历史题材特殊注意事项

- **查证历史细节**：宫殿名称（公主住寿安宫不是坤宁宫）、人物关系、历史事件时间线
- **避免政治敏感词**：朝代更替、民族对立、正统/复国等概念需谨慎
- **书名要求**：
  - 要诗意、要吸引人
  - 能看出主题
  - 不能有政治敏感风险
  - 不直接使用已有经典作品名称（如粤剧《帝女花》）
- **多视角叙事**：增加史诗感，但需在章纲中明确每章的 POV

## 审核保护机制

章节元数据中标注 `审核状态：已完成` 的章节，禁止修改正文和元数据。
