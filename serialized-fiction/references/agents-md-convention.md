# AGENTS.md Convention

> A fiction repository can carry its own AGENTS.md that governs all fanfic work inside it. This is the convention it is expected to follow.

## AGENTS.md Location

The repository root: `<fiction-repo>/AGENTS.md`

## Key Rules from AGENTS.md

1. **Required startup**: Read `skills/serialized-fiction/SKILL.md` before any fanfic work (covers structure, pacing, and chapter writing)
2. **File reading discipline**: Prefer targeted search before opening files; never scan the whole repository
3. **Canon is read-only**: Never overwrite canon facts
4. **Fanon is writable**: New settings go in `fanon/`, not just in chapter prose
5. **Chapter metadata required**: Every chapter must have paired metadata
6. **OOC prevention**: Check character files before writing

## Read Order for Continuing an Existing Project

1. `skills/serialized-fiction/SKILL.md` (covers structure, pacing, and chapter writing)
2. Root `README.md`
3. Project root `README.md`
4. Relevant `canon/*.md`
5. Relevant `fanon/*.md`
6. Latest relevant `chapters/*-元数据.md`
7. Current target chapter or draft

## Notes Location

Working notes go in `notes/` inside the repository. When the user points out a recurring writing issue, record it there. If it has reusable value, update the relevant skill or checklist too.
